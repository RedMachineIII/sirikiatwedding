### Remote git
```
git init
git remote add origin https://github.com/RedMachineIII/sirikiatwedding.git
```

### Clone git
```
git clone https://github.com/RedMachineIII/sirikiatwedding.git
```

### Remote status
```
git remote -v
git status
git branch -vv
git pull origin main --rebase
```

### Push git
```
git add .
git commit -m "Initial commit change"
git branch -M main
git push -u origin main
```

### Fetch git 
```
git fetch
```

### Pull git
```
git pull
git pull origin main
```
